# Gesture Catalog

Define gesture names and usage rules here.
The backend reads this table and returns the best `gesture` with each reply.

| gesture | when_to_use | description |
| --- | --- | --- |
| neutral_idle | Default informational response | Calm neutral state |
| greet_wave | User greets or starts a new session | Friendly greeting |
| explain_point | Assistant explains concepts, steps, architecture | Explanatory pointing motion |
| suggest_action | Assistant recommends options, links, next actions | Recommendation gesture |
| celebrate_success | User confirms success or completion | Positive confirmation gesture |
| empathy_soft | User reports errors, confusion, or frustration | Soft empathy gesture |
